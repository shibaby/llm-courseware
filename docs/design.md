# 大模型技术概念培训课件 — 设计稿

> 日期：2026-10-19 ｜ 状态：待用户批准
> 产出物：一份自包含的单文件 HTML 交互课件
> 修订记录：2026-10-19 通过「builder check」审查；5 项疑问已决策消化（见第 11 节）

## 1. 意图与背景（Why）

用户（自称"小白"）想系统搞懂大模型生态里的一堆概念——MCP、Skills、Agent、Prompt、
Function Calling、RAG、微调、多 Agent、上下文等——并希望产出一份 HTML 培训课件：

- **自学用**：自己看，一遍搞懂
- **讲演用**：可以拿去向别人（同事/朋友）演示讲解
- **核心诉求**：要有交互、有动画，好看到"加深记忆忘不掉"

## 2. 目标 / 非目标 / 反目标

**目标**
1. 1 小时左右可通读全篇（标准版深度）
2. 每个概念都有：生活化的强比喻 + 可视化插画 + 可动手玩的交互；形式分两级——
   第 2 章每个概念配轻量微演示（10–30 秒可玩），Agent/MCP/Skills 等主干概念另有章节级大演示
3. 看完能记住：统一比喻体系 + 章末「记住这个」+ 结尾总图/口诀/测验三重加固
4. 完全离线可用：双击即开，不依赖网络、安装、任何外部资源
5. 中文讲解，术语保留英文原名（如 Agent、MCP），方便日后对照英文资料

**非目标（明确不做）**
- 不教写代码、不讲 API 调用细节（不是开发教程）
- 不讲模型训练的数学原理
- 不做多页面站点、不需要服务器

**反目标（做出来就算失败）**
- 纯文字堆砌、像教科书——每屏必须有视觉元素
- 为炫技牺牲流畅与可读性——动画必须轻量、丝滑
- 信息过时——所有事实以 2026-10 现状为准（见第 7 节）
- 术语轰炸——每个英文词出现时必须紧跟人话解释

## 4. 视觉规范（深空霓虹）

- **背景**：径向渐变 `#101a35 → #070a16 → #04050c`（深空蓝黑）
- **主渐变**：青 `#22d3ee` → 靛紫 `#818cf8` → 粉紫 `#f0abfc`（用于标题渐变字、按钮、进度条、光晕）
- **正文**：主 `#dbe6ff` / `#c7d5f2`，次要 `#8fa0c0`
- **卡片**：`rgba(255,255,255,.035)` 底 + `rgba(148,180,255,.16)` 边框 + 圆角 10–12px 玻璃质感
- **光晕**：霓虹 `box-shadow`（青/紫），标题用渐变文字 + 微光
- **字体**：系统字体栈（"Segoe UI" / "Microsoft YaHei" 等），不引外链字体
- **动效基调**：呼吸发光、渐变流动、星星粒子（轻量）、连线生长

## 5. 课程结构（7 章 + 各章互动演示）

统一版式（第 1–6 章）：顶部进度条 + 目录抽屉；正文含「章节标题 → 一句话核心 → 比喻插画（CSS 绘制）→ 知识卡片 → 互动演示区 → 记住这个高亮框 → 上一节/下一节」。

**导航与讲演机制（混合式 C 的落地定义）**：
- **翻页单位 = 节**：每章由若干节组成（约「核心/插画/卡片/演示/记忆」各一节，长内容可拆）。页面可自由滚动（自学舒服），键盘 `→` / `空格` / `PageDown` 平滑跳到下一节，`←` / `PageUp` 回上一节，`Home` 回封面
- **进度条 = 全文滚动进度**（章节节点在条上标出）；目录抽屉列 7 章，展开可跳任意节
- **无解锁门槛**：不强制看完演示才能翻页；第 2 章地图带「已探索 x/10」计数鼓励点满
- **讲演友好**：右上角全屏按钮（⛶）；正文基准字号 17–18px、标题特大，适配投影；每个演示都带「重来」按钮便于现场重演
- **2026-10-19 追加（优先于本节其余描述）**：改为 PPT 式一屏一页固定舞台，页面与节内均不出现滚动条；顶部固定条显示章节 + 本节知识点，底部固定条显示当前页 / 总页数；详见 §12

### 第 1 章 · 大模型是什么（约 6 分钟）
- 核心比喻：**文字接龙大师**
- 知识点：①训练=海量阅读，使用=预测下一个词；②三个"不能"：不知道新事（知识截止）、不记你（只有临时工作台=上下文）、动不了手；③会自信地胡说（幻觉）
- 互动演示：**文字接龙机**——点按钮，一句话被逐词"接"出来，候选词有跳动/概率感
- 记住这个：它是一颗超级大脑，但被关在聊天框里
- 作用：埋下伏笔——后面所有技术都是在给这颗大脑补"手、记忆、参考书、手册"

### 第 2 章 · 概念全家桶（约 12–15 分钟）【用户特别要求：全部介绍】
- 形式：**可点击的概念地图**——点缀式卡片网络，点每个概念展开"定义 + 比喻 + 迷你例子 + 常见误区"；地图即本章互动演示区（统一版式其余环节照常）
- 每个概念配**轻量微演示**（10–30 秒，点击即玩）：
  1. **Token 词元** — AI 眼里的"字块"，乐高积木；计费与上下文的单位 · 微演示：一句话被切成乐高块、拼回原句
  2. **上下文 Context / 上下文窗口** — AI 的临时工作台/白板 · 微演示：聊得越长"桌面"越满，满了提示"该清一清了"
  3. **Prompt 提示词** — 给下属的工单：说清任务/背景/格式 · 微演示：切换"敷衍提问 vs 好工单"，看输出差别
  4. **Function Calling / Tool 工具调用** — 给大脑配的手 · 微演示：点"查天气"，看 AI 下单 → 工具执行 → 结果回填三步
  5. **RAG 检索增强** — 开卷考试：先翻资料再回答；顺带一句话解释 embedding（把文字变成"意思坐标"）· 微演示：提问后书架亮起、抽出最接近的资料
  6. **微调 Fine-tuning** — 回炉进修 · 微演示：切换"开卷考试（RAG）vs 回炉进修（微调）"两种画面
  7. **Agent 智能体** — 实习生：给目标，自己想办法干完（第 3 章详讲）· 卡片上放"去第 3 章"入口
  8. **多 Agent Multi-Agent** — 团队作战 · 微演示：一个任务被三个小人分走各干一摊
  9. **MCP** — AI 世界的 USB-C 插座（第 4 章详讲）· 卡片上放"去第 4 章"入口
  10. **Skills** — 员工手册：经验写下来，随用随取（第 5 章详讲）· 卡片上放"去第 5 章"入口
- 地图顶部带「已探索 x/10」计数，点满有小小庆祝；地图可自由探索，不设门槛
- 收尾：**全家福口诀**（一句话串起全部 10 个概念，与第 7 章呼应）

### 第 3 章 · Agent 智能体（约 8 分钟）
- 定义与对比：Chatbot 是问答机，Agent 是办事员；Agent = 模型（大脑）+ 工具（手脚）+ 循环（想→做→看→再想）
- 引入 ReAct 直觉（Reason 想 + Act 做），不做学术展开
- 互动演示：**任务步进机**——"帮我订去北京的票"，点「走一步」：想（规划）→ 调工具 → 看结果 → 再想……循环图高亮流转，直到完成
- 常见误区：Agent ≠ 更聪明的模型；Agent = 模型 + 脚手架
- 记住这个：大脑 + 手脚 + 自己转圈，直到把事情办完

### 第 4 章 · MCP（约 8 分钟）
- 问题引入：M 个 AI 应用 × N 个工具 = 定制接口爆炸
- 解决：一个标准插口 → M+N；比喻 USB-C
- 结构动画：Host（你用的应用）→ Client → Server（工具方）三层数据流
- 互动演示：**连线爆炸动画**——先看一团乱麻（每个 AI 连每个工具），点「装上 MCP」，乱麻收拢成整齐的星形网络
- 事实卡片（2026-10 现状）：2024-11 Anthropic 发布 → OpenAI、Google、微软、AWS 相继采用 → 2025-12 捐给 Linux 基金会（Agentic AI Foundation）→ 官方注册表约 4 万+ 服务器 → 2026-07 规格改为无状态
- 常见误区：MCP 不是模型、不是 AI 本身，是"接口标准"（如 USB-C 不生产电器）
- 记住这个：MCP = AI 世界的 USB-C

### 第 5 章 · Skills（约 7 分钟）
- 问题引入：每次都要重复教 AI 同样的做法？提示词写一遍只能用一次
- 解决：把流程写成"手册"（SKILL.md），AI 按需自己翻
- 核心机制：**渐进式披露三层加载**（①名字+描述常驻，仅一行 ~100 token；②正文，触发时读 <5k token；③附属文件与脚本，按需才碰；脚本只把输出送进上下文）
- 互动演示：**三层书页动画**——点击/拖动逐层揭开，实时显示"上下文占用"数字变化
- 与 Prompt 的区别：Prompt 是一次性口头交代，Skill 是写进员工手册
- 触发机制：description 决定"我什么时候该用它"
- 彩蛋：你现在用的工具（OpenCode）里就跑着 Skills，本课件制作过程本身就是演示
- 记住这个：Skills = 把经验写成手册，需要时自己翻

### 第 6 章 · 实战串联（约 8 分钟）
- 场景：用 AI 把"季度工作总结"变成一份 PPT，全程只说了几句话
- 逐步点亮流程图：Prompt 提需求 → Agent 接单 → 触发 PPT Skills（渐进披露动效）→ 通过 MCP 连接文件/表格/PPT 工具 → Function Calling 循环（读数据→写大纲→生成→检查→修改）→ 缺知识时 RAG 翻资料 → 多 Agent 分工（表格员/设计员/校对员）→ 交付
- 互动演示：**流程图逐步点亮**，每个已学概念作为标签一个个亮起
- 收束句：所有技术都是为了一件事——让 AI 从"会聊天"变成"能干活"
- 记住这个：完整链条口诀

### 第 7 章 · 记忆加固（约 5 分钟）
- **总结大图**：星系图——大脑居中，四周环绕补上的能力，**覆盖全部 10 个概念**（话术/工单 Prompt、工作台 上下文、乐高块 Token、手 工具、参考书 RAG、回炉 微调、插座 MCP、手册 Skills、实习生 Agent、团队 多 Agent）
- **顺口溜**：朗朗上口的一句话口诀（文字在实现期润色定型），**把全部 10 个概念串起来**
- **互动测验**：**10 道选择题，每个概念至少 1 题**；答对触发霓虹粒子庆祝动画；答错给提示可重试；结尾计分+鼓励
- 完结彩蛋

## 6. 记忆系统（"忘不掉"机制设计）

1. **统一比喻体系**（全 10 个概念各归其位）：大脑被关在框里 → 给它配：话术（Prompt）、工作台（上下文）、乐高块（Token）、手（工具）、参考书（RAG）、回炉（微调）、插座（MCP）、手册（Skills）、实习生（Agent）、团队（多 Agent）
2. **动画绑定比喻**：每个比喻都配可玩动画（微演示或章节大演示）
3. **复现策略**：主干概念（Agent / MCP / Skills）三次复现（全景 Ch2 → 深潜 Ch3/4/5 → 实战 Ch6）；其余概念至少两次（全景 Ch2 + 总结/测验 Ch7），并在 Ch6 实战中作为环节露面
4. **章末锚点**：「记住这个」高亮框 + 结尾顺口溜（覆盖 10 概念）+ 测验（10 题）
5. **参与感**：所有演示都要用户亲手点/拖，不做自动播放；每个演示带「重来」按钮

## 8. 技术方案

- **单文件** `index.html`：内联全部 CSS/JS，零外部请求，`file://` 双击可用
- **交互**：Vanilla JS；**动画**：CSS keyframes/transition 为主（transform/opacity 优先），少量 JS 驱动
- **响应式**：≥1024px 为最佳（笔记本/投影）；≥768px 可用
- **性能**：每屏动画轻量；避免长任务；总文件目标 < 1MB
- **兼容目标**：现代 Chrome / Edge（Windows 11）

## 12. 2026-10-19 用户追加：PPT 式一屏一页

实现过程中用户明确提出并确认，以下约定优先于第 5 节的滚动式导航：

- **一屏一页**：每个「节」恰好占浏览器一个整屏，翻页即整屏切换；相邻页内容绝不渗出
- **禁滚动**：页面与节内都不出现滚动条；内容超高时整体等比缩放（`transform: scale`，上限 1）适配一屏，不启用内部滚动
- **顶部信息条**：显示当前章节名 + 本节知识点；右上角保留目录 / 全屏按钮
- **底部信息条**：居中显示「当前页 / 总页数」，两侧为课程名与翻页提示
- **概念卡 3D 翻转**：概念地图保持紧凑网格；点击卡片以翻转动画进入单卡详情（左文右演示），可返回地图；已探索计数不变
- **导航**：键盘 / 滚轮翻页、目录跳节、进度条按页索引计算；全屏与「重来」按钮保留

实现细节（自适应缩放、`fitSlide`、`.slide-inner`、deck 顶底栏）以 `index.html` 为准；本节的验收口径是：任意视口尺寸下都不出现滚动条，且一屏只看到一页。
