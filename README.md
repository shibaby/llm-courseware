# 大模型技术概念 · 一小时通关

一份单文件、零依赖的交互式 HTML 课件：从 Token 讲起，把 Prompt、Function Calling、RAG、微调、Agent、多 Agent、MCP、Skills 串成一条线。适合自己自学，也适合投屏讲给别人听。

## 怎么打开

- 双击 `index.html`，用现代 Chrome / Edge 打开即可，**离线可用**，不需要安装任何东西。
- 建议窗口宽度 ≥1024px；投影或全屏效果最佳。

## 怎么讲演

- 点右上角 **⛶** 进入全屏。
- **← / →**、**空格 / PageUp / PageDown** 翻页；**Home** 回封面。
- 点右上角 **目录** 展开 7 章，可直接跳到任意一节。
- 每页都固定显示「章节 + 本节知识点」，底部显示「当前页 / 总页数」。
- 每个演示都有「重来」按钮；第 7 章的测验答错会给提示，答对自动进入下一题。

## 怎么改

- 全部内容都在 `index.html` 一个文件里：HTML、CSS、JS 都是内联的。
- 打开 `index.html#selftest`（或加查询串避免缓存，如 `index.html?v=1#selftest`）可运行页面内自检。
- 修改后运行：

  ```powershell
  node tests/check.cjs
  ```

  该脚本零依赖，会检查单文件约束、四个插入哨兵、文眼、体积等。需要本地服务做浏览器验证时：

  ```powershell
  node tests/serve.cjs
  # 打开 http://127.0.0.1:8137/
  ```
