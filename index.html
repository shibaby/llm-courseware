第 1 章 · 大模型是什么

约 6 分钟

它本质是一台「文字接龙大师」

先忘掉“神经网络”“人工智能”这些吓人的词。大模型做的事只有一件：看着前面的文字，猜下一个词。训练时，它把海量书籍、网页、代码读了个遍；使用时，它把你说的每句话当成“接龙的开头”，一个词一个词往下接。

训练 = 海量阅读使用 = 预测下一个词输出 = 一个词一个词往外蹦
今天→ 天气→ 真→ 好→ ……

所以它不是在“查资料”，而是在“接话”。这也解释了它为什么有时特别会说，有时却一本正经地胡说八道。

超级大脑，但有三个「不能」

不能 01

不知道新事

训练数据有时间截止点，之后发生的事它天然不知道。想让它知道，就得把资料递给它——这就是后面 RAG 要干的事。

不能 02

不记你

它只有一个临时工作台叫上下文。新开一个对话，工作台就清空了；聊得越久，台面越满。

不能 03

动不了手

它只能输出文字，不能真的订机票、查天气、改文件。要动手，就得给它配工具（Tool）。

副作用

会自信地胡说 = 幻觉

因为它只负责“接得像”，不负责“接得对”。遇到不确定的地方，它也可能用非常肯定的语气编一个答案。重要结论务必自己核对，或让它给出处。

把人话记住：它是一颗超级大脑，但被关在聊天框里。后面所有技术，都是在给它补东西。

亲手接一次龙

点「开始接龙」，看它如何只做一件事：每一步，从候选里挑一个最可能的词。

输入（Prompt）

他每天早晨

注意：它不会“想清楚整句话”再开口，而是每 500 毫秒猜一个词，猜完再猜下一个。

记住这个 大模型是一颗超级大脑，但被关在聊天框里。它不知道新事、不记你、动不了手，还会自信地胡说。后面所有技术，都在给它补手、记忆、参考书和员工手册。

接下来先逛一张“概念全家桶”地图，把 Token、Prompt、RAG、MCP、Skills、Agent 这些词一次认全；然后再逐个拆开。

概念卡片

已探索 0/10

是什么模型读写文字的最小单位。文字先被切成一个个 token，模型才能处理。

比喻乐高积木：句子是拼出来的，token 就是那一块块积木。

迷你例子“大模型”三个字可能切成 1–3 个 token；英文长单词常被拆成好几块。

常见误区以为按“字数”计算。计费、上下文上限、输出长度都按 token 算，中英文切法还不一样。

我喜欢学习大模型

AI 眼里没有“字”，只有一块块 Token——计费和上下文都按它算。

是什么模型这一次能“看见”的全部文字：系统提示、聊天记录、贴进去的资料、工具返回结果。

比喻一张工作台：桌面就那么大，摊满了就没地方放新东西。

迷你例子聊到第 50 轮，早期内容可能被挤出窗口；新开一个对话，台面直接清空。

常见误区把它当长期记忆。上下文是临时工作台，不会自动跨会话保存。

上下文工作台容量有限

桌面快满了——这就是上下文窗口，满了就该清一清 / 总结一下。

是什么你交给模型的工单：角色、任务、材料、输出要求，都在这里说清。

比喻一张工单：写得越具体，交付越靠谱。

迷你例子“帮我写个总结” vs “你是产品经理，用 5 条要点总结这份会议记录，每条不超过 30 字”。

常见误区把 Prompt 当咒语，觉得越长越玄。清晰、具体、带例子，通常比堆词更有效。

帮我写点东西。

好的，你想写什么？请提供主题、读者和字数要求。

你是数据分析师。把 3 条销售数据写成周报：华东 +12%、华南 -4%、华北 +7%。用 3 条要点，每条不超过 25 字，最后给一句建议。

本周销售速览
· 华东增长 12%，表现最强
· 华南下滑 4%，需排查原因
· 华北增长 7%，保持稳定
建议：下周重点复盘华南下滑原因，并复制华东打法。

是什么模型不直接干活，而是输出“调用哪个工具、传什么参数”，由外部程序执行，再把结果回填。

比喻给大脑配一双手：大脑下令，手去拿。

迷你例子查天气：模型说 get_weather(city="上海") → 程序调 API → 返回 26°C → 模型再组织回答。

常见误区以为模型自己执行了工具。真正动手的是你的代码或平台，模型只负责选工具、填参数。

1
AI 说

我需要调用查天气工具（上海）。

2
工具执行

get_weather(city="上海") → 晴 · 26°C

3
结果回填

AI 拿到数据，继续组织回答。

今天上海晴，26 度，适合出去走走。

是什么先从你的资料库里检索相关片段，再把片段塞进上下文，让模型“照着材料回答”。（embedding：把文字变成向量，按语义找相近内容）

比喻开卷考试：答案还在书里，只是先帮你翻到了正确那页。

迷你例子企业知识库问答：先检索到《报销制度》第 3 段，再让模型据此回答。

常见误区以为 RAG 会“训练”模型。它不改参数；检索不到、切块不好，回答就会差。

微演示 · 待装填

是什么用一批示例继续训练模型，让它更符合某种风格、格式或判断习惯。

比喻回炉进修：在原有能力上，再上一门专业课。

迷你例子让模型稳定输出公司格式的工单摘要，用几千条标注样本训练。

常见误区拿微调塞频繁变化的知识。知识更新用 RAG 更便宜；微调成本高、周期长。

微演示 · 待装填

是什么模型 + 工具 + 循环：想一步、做一步、看结果、再想下一步，直到完成任务。

比喻一个实习生：会自己查资料、动手试，也会犯错，需要边界和检查。

迷你例子“找出本周新增客户并整理成表”：查数据库 → 读结果 → 补字段 → 输出表格。

常见误区以为 Agent 是更强的模型。它通常是普通模型 + 脚手架（工具、循环、记忆、权限）。

去第 3 章深潜 Agent →

是什么多个角色化 Agent 分工协作，比如一个写、一个查、一个审。

比喻一支团队：有人干活、有人复核，但也要开会同步。

迷你例子写报告：研究员查资料 → 撰稿人写初稿 → 审稿人挑错 → 汇总定稿。

常见误区以为 Agent 越多越好。协调成本和出错面也会上升，先把一个 Agent 跑稳。

微演示 · 待装填

是什么一套开放协议，让 AI 应用用统一方式连接外部工具和数据源（Host ↔ Client ↔ Server）。

比喻USB-C 插座：设备各不相同，接口统一。

迷你例子同一个 MCP 服务器，可以被不同 AI 客户端复用，不必为每个模型重写一遍接入。

常见误区以为 MCP 是模型或某个工具。它是“连接标准”，工具本身还是外部服务。

去第 4 章深潜 MCP →

是什么把一套流程、规范、脚本打包成“技能”，模型按需加载，不必一次全塞进上下文。

比喻员工手册：平时只记目录，遇到任务再翻对应章节。

迷你例子一个“周报技能”包含格式、检查清单和脚本；触发时才读取正文。

常见误区以为 Skills 等于一段长 prompt。它支持分层加载、附带脚本，更像可复用的工作包。

去第 5 章深潜 Skills →

不用一次全记住。第 3–5 章会把 Agent、MCP、Skills 拆开深讲，第 6 章再把所有概念串成一次真实任务。

先送你一段全家福口诀

第 7 章还会再见到它。现在先读一遍，看看能认出几个角色。

Token 切块进上下文，Prompt 写清要干啥；
工具伸手 RAG 翻书，微调回炉改习惯；
Agent 自己转圈圈，多 Agent 分工不忙乱；
MCP 一个插座通天下，Skills 一本手册随叫随看。

读不顺没关系——等第 6 章把它们串成一次“做 PPT”的任务，这段口诀就会自动对上号。

记住这个 这十个词不是十种模型，而是围绕同一颗大脑的十种配件与玩法：Token 是积木，上下文是工作台，Prompt 是工单；工具、RAG、微调负责补能力；Agent、多 Agent、MCP、Skills 把它们组织成能干活的系统。
